GitHub account linking

Understand the contract before you build on it.

For public readers, the short version is: GitHub OAuth proves identity, repo linking proves a legitimate public-repository relationship, and neither one replaces independent receipt verification. The endpoints and payloads are documented today even though a broadly deployed first-party account UI is not claimed here yet.
