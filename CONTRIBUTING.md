# Contributing

Thanks for your interest in Proof of Ship.

## Scope of this public repo

This repository is the public contract + docs + landing-page surface.

Good contributions here include:
- clarifying docs
- improving the public narrative
- tightening schemas/specs
- fixing broken links or public-site issues
- improving static-site accessibility and correctness

This repo is **not** currently the full hosted implementation.

## Local checks

Run the public repo smoke checks:

```bash
python3 -m pytest -q
```

## Contribution guidelines

- Keep claims evidence-backed.
- Do not add private deployment details.
- Do not add secrets, tokens, or environment-specific instructions.
- Prefer small, reviewable pull requests.
